STEP 1先判断：产品需求 or 技术需求？

两类需求的流转路径完全不同，提需求前先确认自己属于哪一类。

📦 产品需求

业务侧发起的功能 / 策略 / 体验类需求，涉及端上与后台研发人力。

→ 看 STEP 2，按业务归属分流 ↓

🔧 技术需求

研发侧自闭环，不走搜索排期会。

→ 直接看下方「技术需求通道」↓

STEP 5如何参与「元宝搜索专项排期会」

  1. 在元宝搜索部 TAPD 空间建单
    建单空间地址：元宝搜索部 TAPD 需求列表
  2. 「是否参加排期会」字段选择：是
    建单时务必勾选，否则需求不会进入排期会评审。
  3. 每周三 17:30 准时参会
    在会上与研发对齐人力投入。
  4. 产品按排定研发人力推进宣讲
    完成宣讲后需求正式进入开发阶段。

VLM如何参与「VLM 专项排期会」

  1. 在元宝搜索部 TAPD 空间建单
    适用于业务需求；评测需求不涉及建单。
  2. 「是否参加排期会」字段选择：是
    建单时务必勾选，否则需求不会进入排期会评审。
  3. 登记需求排期表
    业务排期表：业务需求登记表
    评测排期表：评测需求登记表
  4. 每周三准时参会
    15:00 业务排期、15:30 评测排期，准时参加。
  5. 产品按排定研发人力推进宣讲
    完成宣讲后需求正式进入开发阶段。

技术需求（元宝 / TOB / 公共 / 浏览器业务均适用）统一走研发自闭环，不进入搜索专项排期会。
